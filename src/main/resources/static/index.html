How it works under the hood
  • Add a job or resume: validate, build text, get an embedding from Ollama (768 numbers), save in MongoDB.
  • Match: take the resume's vector, run MongoDB $vectorSearch (cosine similarity), return ranked jobs.
  • Referral click: check Redis, publish an event to Kafka, return a 302 redirect. A consumer then increments the counter.
